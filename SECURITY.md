# Security policy

## Supported versions

Only the latest release on `main` gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/shubham-bodiwal/vitals-doctor/security/advisories/new)). Don't open a public issue.

Include what you found, how to reproduce it and the impact you expect. You'll get a reply within 7 days. Once a fix is ready it is released and the advisory is published, with credit to you if you want it.

In scope: the CLI, the rules and the PageSpeed Insights client. Vulnerabilities in dependencies should go to those projects, but a note here is welcome if this project uses them in an unsafe way.
